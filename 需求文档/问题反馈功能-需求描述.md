# 问题反馈功能 - 需求描述

## 功能概述
用户得到 AI 回答后，可通过反馈按钮提交对本次回答的评价、问题描述与建议；管理员可查看所有用户的问题反馈。

## 核心规则

### 反馈流程
1. 用户得到回答后，点击反馈按钮进入反馈流程。
2. 第一步询问「本次回答是否解决了您的问题？」：
   - 选「是」→ 弹出【对我们的建议】窗口，可输入建议；建议为空也可提交，表示无建议，直接结束。
   - 选「否」→ 进入第二步。
3. 第二步询问「您在本次回答中出现了什么问题？」→ 弹出【问题窗口】：
   - 选择问题分类（生活 / 教务 / 社团 / FAQ 等）。
   - 描述遇到的问题。
   - 同时有【对我们的建议】窗口，可输入建议或不输入，不影响提交。

### 数据保存规则
| 场景 | 是否产生数据 |
|---|---|
| 选「是」且无建议 | 不产生任何数据 |
| 选「是」且有建议 | 保存建议 |
| 选「否」 | 保存问题分类 + 问题描述，若有建议一并保存 |

### 排序
反馈按时间倒序排列，最新的在最上面。

## 管理员查看
1. 仅管理员身份可查看问题反馈。
2. 管理员登录后，主页显示【查看问题反馈】入口（普通用户不显示）。
3. 点击进入【查看问题反馈】界面，采用「历史记录」同款翻页格式（每页 5 条，上一页/下一页）。
4. 界面左上角有「返回主页」按键。
5. 管理员可对「未解决」的反馈执行「标记已解决」，状态变为已解决。
6. 管理员可对「已解决」的反馈执行「删除」，删除后不再占用位置；未解决的反馈不可删除。

## 用户身份
1. 用户分为普通用户（`user`）和管理员（`admin`）。
2. 注册的用户默认为普通用户，身份信息对用户不可见（注册接口不暴露 role）。
3. 管理员账号由后端预置（`admin / 123456`）。

## 正常流程
1. 用户得到 AI 回答 → 点击反馈按钮。
2. 按提示选择「是否解决」，必要时选择分类、填写问题描述与建议。
3. 提交后，反馈数据保存到后端。
4. 管理员登录 → 点击「查看问题反馈」→ 翻页查看所有反馈。
