# 用户注册功能 - 需求描述

## 功能概述
用户通过填写注册表单创建账号，注册成功后跳转至登录页面。

## 注册字段规则

| 字段 | 规则 | 必填 | 唯一性 |
|---|---|---|---|
| 用户名 | 3-20 个字符，只能包含字母、数字、下划线 | 是 | 唯一 |
| 密码 | 6-20 个字符 | 是 | 否 |
| 再次输入密码 | 6-20 个字符，须与密码一致 | 是 | 否 |
| 邮箱 | 符合标准邮箱格式 | 是 | 唯一 |

> 说明：「再次输入密码」仅用于前端校验一致性，不作为独立字段存储。

## 正常流程
1. 用户填写用户名、密码、再次输入密码、邮箱。
2. 点击「注册」按钮。
3. 所有字段格式校验通过，且用户名、邮箱均无重复。
4. 注册成功，跳转到登录页面。

## 异常场景

| 场景 | 提示文案 |
|---|---|
| 用户名已存在 | 用户名已存在 |
| 邮箱已被注册 | 邮箱已被注册 |
| 两次密码不一致 | 密码不一致，请重新输入 |
| 格式不正确 | 提示具体格式错误（如用户名/邮箱格式错误，给出对应字段的具体错误提示） |

## 页面跳转
- 注册成功 → 跳转登录页面。
- 点击页面中的「登录」→ 跳转登录操作。
