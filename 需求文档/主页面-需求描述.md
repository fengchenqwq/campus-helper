# 主页面功能 - 需求描述

## 功能概述
主页面是用户进入系统后的首页，以对话框形式承载对话入口与历史记录，整体风格参考 DeepSeek 对话界面（https://chat.deepseek.com/），要求整洁清晰。

## 页面结构

| 区域 | 说明 |
|---|---|
| 顶部左侧 | 校园百事通 logo / 名称 |
| 顶部右侧 | 用户头像；未登录时显示「登录」，点击跳转登录区域 |
| 中部 | 搜索 / 输入区（对话框形式），支持文字、语音（语音转文字）、拍照（识别图中内容） |
| 输入框下方 | 当前用户的历史对话记录 |

## 核心规则

1. 顶部右侧：已登录显示用户头像，点击头像可退出登录；未登录显示「登录」，点击跳转登录区域。
2. 主页面为对话框形式，打开即显示搜索 / 输入区，输入区支持文字、语音（语音转文字）、拍照（识别图中内容）三种输入方式。
3. 输入框下方展示当前用户自己的历史对话记录；记录较多时只显示最近三次，且以 AI 总结的对话标题作为历史对话记录的名称展示。
4. 用户在输入框输入内容并按回车后，跳转至对话界面。
5. 用户点击某条历史对话记录后，跳转至对话界面并加载该条历史对话记录。

## 页面跳转
- 点击「登录」（未登录状态）→ 跳转登录区域。
- 点击头像（已登录状态）→ 弹出退出登录确认。
- 输入内容回车 → 跳转对话界面。
- 点击历史对话记录 → 跳转对话界面并加载对应记录。
