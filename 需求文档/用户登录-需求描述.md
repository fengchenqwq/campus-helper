# 用户登录功能 - 需求描述

## 功能概述
用户输入用户名和密码进行身份验证，登录成功后进入主页面。

## 登录字段

| 字段 | 规则 | 必填 |
|---|---|---|
| 用户名 | 与注册时一致 | 是 |
| 密码 | 与注册时一致 | 是 |

## 正常流程
1. 用户输入用户名、密码。
2. 点击「登录」按钮。
3. 用户名与密码匹配成功。
4. 登录成功，跳转到主页面。

## 异常场景

| 场景 | 提示文案 |
|---|---|
| 用户名或密码为空 | 提示不能为空 |
| 登录失败（用户名不存在或密码错误） | 用户名或密码错误（不区分具体原因） |

## 页面跳转
- 登录成功 → 跳转主页面。
- 点击页面中的「注册」→ 跳转注册操作。
