# 智能问答功能 PRD（产品需求文档）

## 1. 功能概述
校园助手是「校园百事通」的核心能力。用户在对话界面输入问题，AI 智能体基于校园知识库回答实际问题，并以流式（打字机）方式逐字展示回复。回答内容来源于校园知识库，覆盖教务与考试、校园生活、社团与活动、常见问题 FAQ 四大板块。

## 2. 目标用户与核心场景
- 目标用户：学生、教职工。
- 典型场景：
  - 学生查询选课规则、学分要求、期末/补考安排、绩点计算方法；
  - 询问食堂开放时间、宿舍门禁、校园网连接、澡堂/体育馆时段、快递收发地址；
  - 了解社团介绍、招新时间、讲座预告、志愿活动报名；
  - 查询「图书馆怎么预约座位」「学生证丢了怎么补办」等 FAQ。

## 3. 核心对话流程
1. 用户进入对话界面（由主页面输入回车或点击历史记录跳转而来）。
2. 用户通过文字 / 语音转文字 / 拍照识别图中内容 输入问题并发送。
3. 系统将问题交给 AI 智能体处理。
4. AI 基于校园知识库流式返回答案，前端逐字展示。
5. 对话内容自动保存为当前用户的历史记录。

## 4. 功能需求明细

### 4.1 输入方式
| 方式 | 说明 |
|---|---|
| 文字 | 用户在输入框输入文字并发送 |
| 语音 | 用户说话 → 语音转文字 → 作为问题发送 |
| 拍照 | 拍照/上传图片 → 识别图中内容 → 作为问题发送 |

### 4.2 AI 回复
- 采用流式输出，前端逐字展示（打字机效果）。
- 回复内容基于校园知识库（教务/生活/社团/FAQ）回答。
- 支持多轮对话，保留当前会话上下文。

### 4.3 对话历史
- 对话自动保存，归属当前登录用户。
- 会话标题由 AI 总结对话内容生成（约 20 字），便于识别历史记录。
- 支持查看与加载历史对话记录（承接「历史记录查看」需求）。

### 4.4 新建对话
- 对话界面提供「新建对话」按钮，用户可主动结束当前会话、开启新话题。
- 点击「新建对话」后，当前会话被归档（进入历史记录），对话界面清空并开始新会话。

### 4.5 回溯对话
- 历史记录中展开某条会话，可点击「回溯对话」将其加载到对话界面继续提问。
- 回溯后，该会话的历史消息在对话界面展示，用户可继续发送消息追问。
- 继续追问后，该会话置回进行中（active），从历史记录移除；再次开新对话时才重新归档。

## 5. 业务规则
- 对话允许匿名使用；已登录用户的对话记录归属当前用户，匿名对话不保存历史记录。
- 历史记录按时间倒序排列。
- 创建新对话（含点击「新建对话」）时，满足保留条件（用户提问 >3 次且字数 >100）的上一个会话进入历史记录，不满足的删除。

## 6. 异常场景
| 场景 | 处理 |
|---|---|
| 知识库无匹配答案 | 给出友好兜底回复（如提示换种问法或联系人工） |
| 接口失败 / 超时 | 提示请求失败，可重试 |
| 语音识别失败 | 提示识别失败，引导改用文字输入 |
| 图片识别失败 / 无有效内容 | 提示图片无法识别，引导重新拍照或改用文字 |

## 7. 非功能需求
- 响应速度：问题发送后尽快开始流式返回首字。
- 回复准确性：优先返回知识库内已确认的校园信息。
- 数据安全：对话数据按用户隔离；AI 令牌不暴露给前端。

## 8. 依赖
- Coze 智能体：承载校园助手对话逻辑（环境已有 coze-stream-chat 流式对话实现方案）。
- 校园知识库：教务与考试、校园生活、社团与活动、常见问题 FAQ（50-100 条结构化问答对）。
