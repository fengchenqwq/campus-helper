# 校园百事通助手 - 业务术语表

## 一、用户与账号

| 术语 | 定义 |
|---|---|
| 用户 | 使用校园百事通助手的人，包括学生和教职工 |
| 访客 | 未注册、未登录的用户，仅可查看登录入口，无法使用对话与历史记录功能 |
| 注册用户 | 已完成注册并登录的用户，可使用全部功能 |
| 用户名 | 用户的登录标识，3-20 个字符，只能包含字母、数字、下划线，需唯一 |
| 密码 | 用户的登录凭证，6-20 个字符，明文处理 |
| 邮箱 | 用户注册时填写的邮箱，需符合标准邮箱格式，需唯一 |
| 注册 | 用户填写用户名、密码、邮箱创建账号的过程 |
| 登录 | 用户输入用户名和密码验证身份、进入系统的过程 |

## 二、对话与会话

| 术语 | 定义 |
|---|---|
| 校园助手 | 基于 AI 的智能体，负责回答用户提出的校园问题 |
| 对话界面 | 用户与校园助手进行交流的页面 |
| 会话 | 一次多轮对话的容器，包含多条消息 |
| 消息 | 会话中的一条内容，分为用户消息（user）和 AI 消息（ai） |
| 多轮对话 | 在同一会话中连续多次问答，AI 保留上下文 |
| 历史记录 | 已归档的会话，供用户回看之前的对话 |
| 归档 | 会话结束并进入历史记录的过程/状态（创建新对话时触发） |
| 关键词 | 历史记录列表中用于展示会话名称的简短文字 |
| 流式回复 | AI 逐字返回并展示回复的方式，即打字机效果 |

## 三、输入方式

| 术语 | 定义 |
|---|---|
| 文字输入 | 用户在输入框输入文字进行提问 |
| 语音转文字 | 用户说话，将语音转换为文字后进行提问 |
| 拍照识别 | 拍照或上传图片，识别图中内容后进行提问 |

## 四、知识内容

| 术语 | 定义 |
|---|---|
| 知识库 | 校园百事通的知识内容集合，供 AI 回答问题时引用 |
| 教务与考试 | 选课规则、学分要求、期末考试、补考重修、绩点计算等内容 |
| 校园生活 | 食堂开放时间、宿舍门禁、校园网、澡堂/体育馆、快递收发等内容 |
| 社团与活动 | 社团介绍、招新时间、讲座预告、志愿活动报名等内容 |
| FAQ | 常见问题及结构化问答对（50-100 条，如「图书馆怎么预约座位」） |
