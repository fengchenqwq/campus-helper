# 校园百事通助手 - 数据库设计文档

## 一、概述

数据库使用 SQLite，共设计四张表：

| 表名 | 说明 |
|---|---|
| users | 用户表，存储账号信息 |
| conversations | 会话表，一个会话对应一段多轮对话 |
| messages | 消息表，存储会话中的每条消息（多轮问答） |
| knowledge | 知识库表，存储校园知识内容（教务/生活/社团/FAQ） |

## 二、表关系

```
users (1) ────< (N) conversations (1) ────< (N) messages
```

- 一名用户拥有多个会话；一个会话包含多条消息。
- 删除用户时级联删除其全部会话，删除会话时级联删除其全部消息。
- knowledge 为独立知识库，不与用户关联。

## 三、users（用户表）

| 字段 | 类型 | 约束 | 描述 |
|---|---|---|---|
| id | INTEGER | PRIMARY KEY AUTOINCREMENT | 用户 ID |
| username | TEXT | NOT NULL, UNIQUE | 用户名，3-20 个字符，字母/数字/下划线 |
| password | TEXT | NOT NULL | 密码，明文存储，6-20 个字符 |
| email | TEXT | NOT NULL, UNIQUE | 邮箱，标准邮箱格式 |
| created_at | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP | 注册时间 |

## 四、conversations（会话表）

| 字段 | 类型 | 约束 | 描述 |
|---|---|---|---|
| id | INTEGER | PRIMARY KEY AUTOINCREMENT | 会话 ID |
| user_id | INTEGER | NOT NULL, FOREIGN KEY → users.id | 所属用户，用于数据隔离 |
| title | TEXT | 可空 | 会话标题（由 AI 总结对话内容生成，约 20 字），用于历史记录列表展示 |
| status | TEXT | NOT NULL, DEFAULT 'active' | 会话状态：active（进行中）/ archived（已归档） |
| created_at | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP | 会话创建时间 |
| updated_at | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP | 最后更新时间 |

> 说明：用户开始新对话时创建 `active` 会话；当用户「创建新对话」时，将满足保留条件（用户提问 >3 次且字数 >100）的上一个 `active` 会话置为 `archived`（即「放入历史记录」），不满足的删除。历史记录展示 `archived` 会话，按 `created_at` 倒序。回溯对话后继续追问，会话置回 `active`（从历史记录移除），再次开新对话时才重新归档。

## 五、messages（消息表）

| 字段 | 类型 | 约束 | 描述 |
|---|---|---|---|
| id | INTEGER | PRIMARY KEY AUTOINCREMENT | 消息 ID |
| conversation_id | INTEGER | NOT NULL, FOREIGN KEY → conversations.id | 所属会话 |
| role | TEXT | NOT NULL | 消息角色：user / ai |
| content | TEXT | NOT NULL | 消息内容 |
| created_at | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP | 消息时间 |

## 六、knowledge（知识库表）

| 字段 | 类型 | 约束 | 描述 |
|---|---|---|---|
| id | INTEGER | PRIMARY KEY AUTOINCREMENT | 知识条目 ID |
| category | TEXT | NOT NULL | 分类：教务 / 生活 / 社团 / FAQ |
| question | TEXT | NOT NULL | 问题 / 标题 |
| answer | TEXT | NOT NULL | 答案 / 内容 |
| created_at | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP | 录入时间 |

> 说明：FAQ 直接存「问答对」；普通知识内容可将「标题」存 question、「正文」存 answer。支持通过脚本批量导入文件夹中的文件。

## 七、索引

| 索引名 | 字段 | 用途 |
|---|---|---|
| idx_conv_user_time | conversations(user_id, created_at DESC) | 按用户查询会话并倒序 |
| idx_msg_conv_time | messages(conversation_id, created_at) | 按会话查询消息并按时间正序 |
| idx_knowledge_cat | knowledge(category) | 按分类检索知识 |

## 八、建表 SQL

```sql
PRAGMA foreign_keys = ON;

CREATE TABLE users (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    username    TEXT    NOT NULL UNIQUE,
    password    TEXT    NOT NULL,
    email       TEXT    NOT NULL UNIQUE,
    created_at  DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE conversations (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id     INTEGER NOT NULL,
    title       TEXT,
    status      TEXT    NOT NULL DEFAULT 'active',
    created_at  DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at  DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE
);

CREATE TABLE messages (
    id               INTEGER PRIMARY KEY AUTOINCREMENT,
    conversation_id  INTEGER NOT NULL,
    role             TEXT    NOT NULL,
    content          TEXT    NOT NULL,
    created_at       DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (conversation_id) REFERENCES conversations(id) ON DELETE CASCADE
);

CREATE TABLE knowledge (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    category    TEXT    NOT NULL,
    question    TEXT    NOT NULL,
    answer      TEXT    NOT NULL,
    created_at  DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX idx_conv_user_time ON conversations (user_id, created_at DESC);
CREATE INDEX idx_msg_conv_time  ON messages (conversation_id, created_at);
CREATE INDEX idx_knowledge_cat  ON knowledge (category);
```
