# 校园百事通助手 - API 设计文档

## 一、基础信息

- 后端：Python + FastAPI
- 基础地址：`http://127.0.0.1:8000`
- 统一前缀：`/api`
- 数据格式：`application/json`（文件上传接口为 `multipart/form-data`）

## 二、统一响应格式

所有接口统一返回：

```json
{ "code": 0, "message": "ok", "data": {} }
```

| 字段 | 类型 | 说明 |
|---|---|---|
| code | int | 状态码，`0` 成功，非 `0` 失败 |
| message | string | 提示信息 |
| data | object / array / null | 返回数据，失败时为 `null` |

## 三、错误码约定

| code | 说明 |
|---|---|
| 0 | 成功 |
| 1001 | 参数错误 / 格式不正确 |
| 1002 | 用户名已存在 |
| 1003 | 邮箱已被注册 |
| 1004 | 用户名或密码错误 |
| 1005 | 未登录 / 身份无效 |
| 1006 | 无权限访问该数据 |
| 1007 | 操作过于频繁（限流） |
| 1008 | 只能删除已解决的反馈 |
| 5000 | 服务器内部错误 |

## 四、身份标识说明

- 原型阶段简化：登录/注册成功后，前端在 `localStorage` 保存返回的 `user_id`。
- 涉及用户数据的接口携带 `user_id`，后端校验数据归属（数据隔离）。
- 正式版本建议改用 token，此处暂用 `user_id` 便于联调。
- 对话接口 `user_id` 必填，未登录返回 `1005`。
- 登录成功额外返回 `role`（`user` / `admin`），前端据此判断管理员身份；注册默认 `user`，用户不可自选身份。

## 五、接口总览

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | /api/register | 注册 |
| POST | /api/login | 登录 |
| POST | /api/chat | 对话（发送消息，AI 回复） |
| GET | /api/history | 获取历史会话列表 |
| GET | /api/history/{conversation_id} | 获取某个会话的消息详情 |
| GET | /api/conversations | 获取用户所有会话（含进行中/历史） |
| GET | /api/feedback | 获取所有问题反馈（管理员专属） |
| POST | /api/feedback | 提交问题反馈 |
| POST | /api/feedback/{feedback_id}/resolve | 标记反馈为已解决（管理员专属） |
| DELETE | /api/feedback/{feedback_id} | 删除反馈（管理员专属，仅限已解决） |
| POST | /api/voice | 语音转文字 |
| POST | /api/image | 拍照识别图片内容 |
| POST | /api/document | 解析文档（docx/pdf/pptx/xlsx）提取文字 |
| POST | /api/upload | 上传文件返回公网 URL（用于在线预览） |

## 六、接口明细

### 1. 注册

- **POST /api/register**
- **请求体**：

```json
{ "username": "xiaoming", "password": "123456", "email": "a@b.com" }
```

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| username | string | 是 | 3-20 字符，字母/数字/下划线 |
| password | string | 是 | 6-20 字符 |
| email | string | 是 | 标准邮箱格式 |

- **成功响应**：

```json
{ "code": 0, "message": "注册成功", "data": { "user_id": 1, "username": "xiaoming" } }
```

- **失败示例**：

```json
{ "code": 1002, "message": "用户名已存在", "data": null }
{ "code": 1003, "message": "邮箱已被注册", "data": null }
{ "code": 1001, "message": "用户名格式不正确", "data": null }
```

### 2. 登录

- **POST /api/login**
- **请求体**：

```json
{ "username": "xiaoming", "password": "123456" }
```

- **成功响应**：

```json
{ "code": 0, "message": "登录成功", "data": { "user_id": 1, "username": "xiaoming", "role": "user" } }
```

- **失败示例**：

```json
{ "code": 1004, "message": "用户名或密码错误", "data": null }
```

### 3. 对话

- **POST /api/chat**
- **请求体**：

```json
{ "user_id": 1, "content": "图书馆怎么预约座位？", "conversation_id": null }
```

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| user_id | int | 是 | 当前用户（必须登录后才能对话） |
| content | string | 是 | 用户输入的问题 |
| conversation_id | int | 否 | 会话 ID；为空表示新对话，有值表示继续该会话 |

- **逻辑**：
  1. `user_id` 为空 → 返回 `1005`（请先登录后再提问）。
  2. 限流：每个用户每分钟最多 10 次对话，超限返回 `1007`（提问过于频繁）。
  3. `conversation_id` 为空 → 归档满足条件的 `active` 会话（用户提问 >3 次且字数 >100），其余删除，创建新 `active` 会话。
  3. `conversation_id` 有值 → 校验会话归属当前用户（否则返回 `1006`），并把会话置回 `active`。
  4. 保存用户消息（role=user）。
  5. 调用 AI 获取回复，保存 AI 回复（role=ai）。
  6. 用 AI 总结对话内容生成会话标题（约 20 字），并更新 `updated_at`。
- **成功响应**：

```json
{ "code": 0, "message": "ok", "data": { "conversation_id": 2, "ai_reply": "登录图书馆公众号或预约系统……" } }
```

### 4. 获取历史会话列表

- **GET /api/history?user_id=1&limit=3**
- **参数**：

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| user_id | int | 是 | 当前用户 |
| limit | int | 否 | 返回条数，为空返回全部（主页面取最近三次传 3） |

- **逻辑**：返回该用户 `archived` 会话，按 `created_at` 倒序。
- **成功响应**：

```json
{
  "code": 0,
  "message": "ok",
  "data": [
    { "conversation_id": 1, "title": "图书馆怎么预约座位", "created_at": "2026-10-17 14:32" }
  ]
}
```

### 5. 获取会话消息详情

- **GET /api/history/{conversation_id}?user_id=1**
- **逻辑**：校验会话归属后，返回该会话全部消息，按 `created_at` 正序。
- **成功响应**：

```json
{
  "code": 0,
  "message": "ok",
  "data": [
    { "role": "user", "content": "图书馆怎么预约座位？", "created_at": "2026-10-17 14:30" },
    { "role": "ai",   "content": "登录图书馆公众号……", "created_at": "2026-10-17 14:30" }
  ]
}
```

### 6. 语音转文字

- **POST /api/voice**（`multipart/form-data`）
- **请求**：上传音频文件，字段名 `file`。
- **成功响应**：

```json
{ "code": 0, "message": "ok", "data": { "text": "图书馆怎么预约座位？" } }
```

- **失败示例**：

```json
{ "code": 1001, "message": "语音识别失败", "data": null }
```

### 7. 拍照识别图片内容

- **POST /api/image**（`multipart/form-data`）
- **请求**：上传图片文件，字段名 `file`。
- **成功响应**：

```json
{ "code": 0, "message": "ok", "data": { "text": "（识别出的图中文字内容）" } }
```

- **失败示例**：

```json
{ "code": 1001, "message": "图片无法识别", "data": null }
```

### 8. 获取用户所有会话

- **GET /api/conversations?user_id=1**
- **逻辑**：返回该用户全部会话（含 `active` 进行中 和 `archived` 历史），按 `updated_at` 倒序。
- **成功响应**：

```json
{
  "code": 0,
  "message": "ok",
  "data": [
    { "conversation_id": 1, "title": "图书馆怎么预约座位", "status": "active", "created_at": "2026-10-17 14:32" }
  ]
}
```

### 9. 获取问题反馈（管理员专属）

- **GET /api/feedback?user_id=1**
- **逻辑**：校验 `user_id` 对应角色为 `admin`（否则返回 `1006`），返回全部问题反馈，按 `created_at` 倒序。
- **成功响应**：

```json
{
  "code": 0,
  "message": "ok",
  "data": [
    { "feedback_id": 1, "username": "xiaoming", "solved": false, "category": "生活", "problem": "无法打开图书馆预约", "suggestion": "希望更快", "created_at": "2026-10-18 10:00" }
  ]
}
```

### 10. 提交问题反馈

- **POST /api/feedback**
- **请求体**：

```json
{ "user_id": 1, "conversation_id": 5, "solved": false, "category": "生活", "problem": "无法打开图书馆预约", "suggestion": "希望更快" }
```

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| user_id | int | 是 | 提交反馈的用户 |
| conversation_id | int | 否 | 关联会话 |
| solved | bool | 是 | 是否解决：true 已解决 / false 未解决 |
| category | string | 否 | 问题分类（未解决时填写）：生活 / 教务 / 社团 / FAQ |
| problem | string | 否 | 问题描述（未解决时填写） |
| suggestion | string | 否 | 用户建议（可空） |

- **成功响应**：

```json
{ "code": 0, "message": "反馈提交成功", "data": null }
```

### 11. 标记反馈为已解决（管理员专属）

- **POST /api/feedback/{feedback_id}/resolve?user_id=1**
- **逻辑**：校验 `user_id` 为 `admin`（否则 `1006`），把该反馈 `solved` 置为 1。
- **成功响应**：

```json
{ "code": 0, "message": "已标记为已解决", "data": null }
```

### 12. 删除反馈（管理员专属，仅限已解决）

- **DELETE /api/feedback/{feedback_id}?user_id=1**
- **逻辑**：校验 `user_id` 为 `admin`（否则 `1006`）；反馈不存在返回 `1001`；反馈未解决返回 `1008`。
- **成功响应**：

```json
{ "code": 0, "message": "反馈已删除", "data": null }
```

### 13. 解析文档

- **POST /api/document**（`multipart/form-data`）
- **请求**：上传文档文件，字段名 `file`（支持 docx / pdf / pptx / xlsx）。
- **成功响应**：

```json
{ "code": 0, "message": "ok", "data": { "text": "（文档提取的文字内容）" } }
```

- **失败示例**：

```json
{ "code": 5000, "message": "文档解析失败或内容为空", "data": null }
```

### 14. 上传文件（在线预览）

- **POST /api/upload**（`multipart/form-data`）
- **请求**：上传文件，字段名 `file`。
- **逻辑**：保存到服务器 `uploads/` 目录，返回公网 URL，供 Office 在线预览使用。
- **成功响应**：

```json
{ "code": 0, "message": "ok", "data": { "url": "http://124.221.22.10:8000/uploads/xxx.docx" } }
```
